Miami-Dade College Calorie Nutrition Tracker

A lightweight, free, and intuitive desktop software application designed specifically to help students track and manage their daily calorie intake, maintain balanced nutrition, and build consistent health habits amidst demanding academic schedules.
📌 Project Overview

Many commercial calorie trackers are bloated with unnecessary features, require paid subscriptions, or lack simplicity. Developed as a dedicated tool for Miami-Dade College, this application provides a streamlined, accessible solution without financial or technical barriers, empowering students to maintain the energy levels required for academic success.
✨ Key Features

    Dynamic Calorie Tracking Dashboard: Provides a real-time visual comparison between your daily target calorie limits and current consumption, updating dynamically as entries are added or removed.

    Interactive Daily Food Log: View all items consumed throughout the day with their respective calorie values, featuring quick-action delete buttons for effortless modifications.

    Customizable Calorie Goals: Easily edit and set personalized daily calorie targets as your personal health goals evolve.

    My Foods Library: A dedicated management page equipped with custom inputs for food names and calorie amounts, allowing you to save favorite items for quick tracking.

🚀 How to Compile and Run

To run and test the application locally, follow these steps:

    Please Visit ” https://github.com/jferr006/MDC-Nutrition-Calorie-Tracker/tree/main ” to access all necessary documentation.

    Open the project directory inside Visual Studio Code (or your preferred Java IDE).

    Verify Dependencies: Ensure your Java Runtime Environment (JRE) and JavaFX SDK are correctly configured in your environment path.

    Locate and execute the launcher file:
    Navigate to the experimental launcher at the following path within the project structure:
    \mdccalorietracker\src\main\java\com\example\mdc\Launcher.java

    Run Launcher.java to start the graphical user interface (GUI) application.
